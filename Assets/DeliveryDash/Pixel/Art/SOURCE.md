# Pixel game art

`TownDescent.png`, `TownMarket.png`, `TownFinish.png`, and `CourierCart.png` were generated for this project from the owner-selected visual target in `references/deliverydash-pixel-target.png`. They are project-specific production art, not third-party stock assets. The six original reference images remain in `references/` unchanged.

The three town images are backdrop plates. Route shape, stones, hazards, and branch surfaces are rendered separately in-game so the player sees motion and can make steering choices.
